StreakKit Developer Documentation

StreakKit is an open-source, code-first retention and streak infrastructure engine. It replaces \$299–\$999/month commercial platforms (such as Trophy.so) with deterministic, offline-first state machines, universal embed UIs, and pure in-code configuration.

⚡
Zero Web Dashboard
No external portals or synced metric mappings. Targets, cadence, rest days, and auto-freezes are declared in source code.
❤️
Duolingo-in-a-Box
Complete gamification engine: 5/5 Hearts with 4-hr background auto-refill, virtual Gems, 0/20 XP daily goals, and winding lesson paths.
🕊️
Streak Amnesty
Recovers churned users who lost multi-week streaks by offering 48-hour resurrection campaigns after 14 days of inactivity.
📱
1-Line Native Embeds
Opens 60fps vector animated modals and S-curve learning paths in any Android BottomSheet, iOS sheet, Flutter view, or WebView.
The Zero-Dashboard Philosophy

In traditional gamification SDKs, developers must navigate a web dashboard, register an organization, manually configure metric IDs, create reward rules, and hardcode slugs. If a field desynchronizes, user streaks silently fail. With StreakKit, the application code itself is the source of truth. Rules auto-provision and sync seamlessly on startup.

3-Minute Quickstart

Drop the 1-file SDK into your mobile or web project, declare your streak rule inline, and record activity on user actions: 

// 1. Initialize once in MainActivity or Application class:
StreakKit.init(
    context = this,
    rules = listOf(
        StreakRule(
            slug = "daily_lesson",
            name = "Daily Lesson",
            target = 1,
            cadence = "DAILY",
            gracePeriodMinutes = 120, // Activity until 2:00 AM counts toward yesterday
            daysOff = listOf(0),       // Sundays are rest days (no streak break)
            maxFreezes = 3,
            freezeAutoEarnDays = 7    // Auto-earn +1 freeze every 7 consecutive days
        )
    )
)

// 2. Ping when user finishes a task:
StreakKit.ping(this, "daily_lesson", userId = "user_123")

Client SDK Integration

Android (Kotlin / Java)

StreakKit provides a single-file Android drop-in (StreakKit.kt) that requires no third-party Gradle dependencies other than OkHttp:

  • Offline Ingestion Queue: If device is offline, requests are persisted to SharedPreferences and flushed on next connect.
  • Duolingo BottomSheet: StreakKit.showModal(activity, "ruleSlug") opens a native bottom dialog rendering the embed with zero external downloads.
  • Learning Path UI: StreakKit.showDuolingoPath(activity, "ruleSlug", flag = "🇳🇬", unitTitle = "Greetings") opens the winding lesson map.
  • Haptics & Audio: Bridges Web Audio synthesis events directly into Android haptic feedback.

Core Engine Mechanics

Code-First Rule Auto-Provisioning

Whenever StreakKit.ping() is called with an optional ruleConfig object, the server creates or updates the rule automatically. You never have to seed a database or maintain configuration dashboards.

Timezone Math & Midnight Grace Periods

To prevent users from losing streaks because they studied or exercised at 12:30 AM, StreakKit calculates the Logical Local Date by subtracting a configurable grace period: 

ShiftedTimestamp = occurredAtUtc - (gracePeriodMinutes × 60 × 1000)
LogicalDate = Intl.DateTimeFormat(userTimezone, ShiftedTimestamp)

With gracePeriodMinutes = 120 (default), any activity completed between 12:00 AM and 02:00 AM Tuesday is mathematically attributed to Monday, saving the user's habit loop.

Rest Days (daysOff)

Habits that should not run on weekends or religious days can declare daysOff (e.g. [0] for Sunday, [5] for Friday, or [0, 6] for weekends). On these days, streaks do not break, and safety freezes are never consumed.

Safety Freezes & Auto-Earn Milestones

Users start with a configurable number of freezes (default: maxFreezes = 2). If a non-exempt day is missed, a freeze is consumed automatically to protect the streak. If configured with freezeAutoEarnDays = 7, the user automatically earns +1 safety freeze for every 7 consecutive streak days (capped at maxFreezes).

Streak Amnesty (Churn Reclamation)

When a user who had a 14+ day streak misses several days, they often churn due to feeling their hard work was wiped out. StreakKit automatically triggers a Streak Amnesty flow if the user has been dormant for 14–90 days:

  • POST /v1/streak/amnesty/evaluate — Checks if a dormant user qualifies for amnesty.
  • POST /v1/streak/amnesty/claim — Atomically restores their broken streak (e.g. 14 days) on their first new activity, bypassing the 0-day reset.

Monotonic Clock & Anti-Cheat Protection

StreakKit collects monotonicMs (from SystemClock.elapsedRealtime() or performance.now()) along with wall-clock time. If a user moves their device clock forward to fake a streak, monotonic skew detection flags the event as CLOCK_SKEW_SUSPECTED and clamps timestamps to current server time.

Duolingo-in-a-Box Gamification Engine

StreakKit includes the complete gamification model popularized by Duolingo, fully implemented as a headless domain engine and a drop-in S-curve Winding Path UI:

❤️ Hearts / Lives & 4-Hour Auto-Refill Math

Users start with 5/5 Hearts. Each mistake or wrong answer deducts 1 heart. When hearts reach 0, outOfHearts: true is returned. Hearts auto-refill at a rate of 1 heart every 4 hours (240 minutes):

  • Auto-refill math is evaluated on read (zero background cron jobs needed).
  • Exact countdown timers (secondsUntilNextRefill, secondsUntilFullRefill) are returned in every status response.
  • Hearts can be refilled immediately with GEMS (50 gems for full refill), PRACTICE (+1 heart), or rewarded AD (+1 heart).

💎 Virtual Gems Ledger

Each user has a virtual gem balance (default start: 50 gems). Gems can be awarded for milestones, spent on streak repairs or heart refills, or transacted via POST /v1/gamification/gems/transaction.

🚩 Daily XP Goal (0/20 XP)

Tracks daily progress (e.g. 0/20 XP). Resets automatically at local midnight. When the user crosses their daily goal for the first time on any day, StreakKit automatically awards +10 bonus Gems.

🗺️ Universal Duolingo Winding Path Embed UI

Serve the full Duolingo home screen in any mobile app with one URL: 

GET /v1/embed/path/:ruleSlug/:externalUserId?flag=🇳🇬&unitTitle=Greetings&unitSubtitle=Say%20hello
  • Top Bar: Language flag, 🔥 Streak count, 💎 Gems balance, ❤️ Hearts count with live refill timer, and ⚙️ settings.
  • Daily Goal Card: 🚩 Daily goal · 0/20 XP with animated progress fill bar.
  • Unit Banner: UNIT 1 · 0/4 Greetings with interactive guidebook button.
  • Winding S-Curve Nodes: Avatar illustration, pulsing START button, active 3D star node, locked chest nodes, and Out of Hearts refill modal.

⚙️ 100% Dynamic & Customizable (Zero Hardcoding)

Nothing is hardcoded. Every single parameter—max hearts, daily XP target, refill interval, gem refill costs—is fully customizable at runtime across 3 layers:

  1. Per-User / Tenant Configuration API: Call POST /v1/gamification/config or SDK configureGamification(...) to set custom heartsMax (e.g. 3 for hard quizzes, 10 for kids, 999 for VIPs), heartsRefillIntervalMinutes (e.g. 30m vs 4 hours), and xpTargetDaily (e.g. 50 XP vs 20 XP).
  2. Dynamic URL Embed Overrides: When loading /v1/embed/path/:ruleSlug/:userId, pass query parameters like ?dailyTarget=50&maxHearts=10&gemCost=30 to immediately customize the UI without touching the database.
  3. Per-Event Overrides: When sending XP events via POST /v1/gamification/xp/add, provide dailyTargetOverride to alter the goal on the fly.

Retention Moats & Notifications

Behavioral Contrast Nudges

StreakKit evaluates psychological contrast between leisurely distraction and neglected habits. It supports 4 psychological archetypes:

Archetype Psychological Trigger Example Generated Copy
GUILT_PRIORITY Time disparity on leisure vs habit "You spent 45m listening to music, but didn't protect your Quran/lesson streak today?"
MOMENTUM_PIVOT Transforming passive scrolling into action "Since you're active right now, take 90 seconds to keep your 12-day streak alive."
IDENTITY_MIRROR Reminding user of their stated identity "You're someone with a 21-day streak. Don't let today be the day you drop the ball."
TIME_TRADE Comparing duration of activity vs habit "That 30m gaming session took 10× longer than the 3m needed to save your streak."

Live Red Chronometer Notification

Android notifications use native setUsesChronometer(true) to display a ticking red countdown clock (⏳ 01:42:15 remaining) in the notification shade, replicating Duolingo's high-urgency panic alerts.

Duolingo-Grade Month Calendar Grid

The embed UI and headless API (GET /v1/streaks/:ruleSlug/:userId/calendar) output month-by-month grid models with gold flame badges for completed days, cyan ice crystals for frozen days, pause indicators, and ✨ Perfect Week banners (7/7 days active).

Procedural Web Audio Dopamine Synthesizer

StreakKit synthesizes triumphant ascending chords and frost shimmers in real-time via the browser's Web Audio API. It requires zero audio asset downloads (no .mp3 or .wav files) and works completely offline.

REST API Reference

Authentication & Base URL

Pass your public or secret API key as a Bearer token in the Authorization header: 

Authorization: Bearer pk_live_your_public_key

POST /v1/ping — Record Activity

Advances streak progress, auto-creates rule if absent, evaluates midnight grace periods, and returns the full streak state in a single roundtrip.

ParameterTypeRequiredDescription
ruleSlugstringYesIdentifier of the streak rule (e.g. daily_reading)
externalUserIdstringYesEnd-user identifier in your system
valuenumberNoProgress value (default: 1)
timezonestringNoIANA Timezone (e.g. Africa/Lagos, America/New_York)
ruleConfigobjectNoOptional rule parameters to auto-provision without a dashboard

Response Schema:

{
  "ruleSlug": "daily_reading",
  "currentStreak": 14,
  "highestStreak": 21,
  "status": "ACTIVE_TODAY",
  "todayProgress": { "current": 1, "target": 1, "completed": true },
  "freezes": { "available": 2, "max": 3 },
  "timing": {
    "currentLogicalDate": "2026-11-08",
    "secondsUntilExpiry": 43200,
    "isExemptToday": false
  },
  "embedUrl": "https://api.streakkit.dev/v1/embed/daily_reading/user_123"
}

GET /v1/streaks/:ruleSlug/:externalUserId — Query State

Returns the user's current streak, history, freezes, and expiry timer without mutating state.
