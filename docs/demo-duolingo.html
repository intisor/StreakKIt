⚡ 3-Line Drop-In SDK
How apps embed this entire gamification engine with zero dashboards:
// 1. Initialize once:
StreakKit.init(context = this, rules = listOf(
    StreakRule(slug = "daily_lesson", name = "Daily Lesson", target = 1)
))

// 2. Ping streak + award XP on lesson completion:
StreakKit.ping(this, "daily_lesson")
StreakKit.addXp(amount = 10, unitId = "unit_1")

// 3. Deduct heart on mistake & open Duolingo Winding Path UI:
StreakKit.consumeHeart()
StreakKit.showDuolingoPath(this, "daily_lesson", flag = "🇳🇬", unitTitle = "Greetings")
